# design

AX 프로젝트의 설계 자산을 누적하는 레포.
개별 프로젝트에서 나온 수정사항과 노하우를 모아 계속 고도화한다.

---

## 구성

| 폴더 | 내용 | 상태 |
|---|---|---|
| [`ux-kit/`](./ux-kit) | 요구사항 → UX 설계 → 화면 시안 → 확정 스펙 규칙 | v0.5.0 |

---

## ux-kit 빠른 설치

커서 채팅에 아래를 붙여넣는다.

```
https://raw.githubusercontent.com/koowoojo/design/main/ux-kit/dist/SETUP-UX-KIT.md
이 파일을 받아서 지시대로 설치해줘.
```

레포가 private이면 `ux-kit/dist/SETUP-UX-KIT.md` 를 직접 첨부하고 "적용시켜줘"라고 입력한다.

자세한 내용은 [`ux-kit/README.md`](./ux-kit/README.md).

## 폴더를 추가할 때

이 레포는 자산 하나당 폴더 하나다. 새 자산을 만들면 아래를 지킨다.

1. **최상위 폴더 하나**로 만든다. 루트에 파일을 흩뿌리지 않는다
2. 그 폴더 안에 **자체 README와 CHANGELOG**를 둔다. 루트 README는 목록만 관리한다
3. **원본 파일이 무엇인지 명시**한다. 생성물은 `dist/` 에 두고 직접 수정을 금지한다
4. 위 표에 한 줄 추가한다

폴더 간에 파일을 공유하지 마라. 공유하고 싶어지면 그건 하나의 자산이라는 뜻이다.

## 원칙

**누적은 저절로 되지 않는다.** 프로젝트가 끝날 때 회고를 남기지 않으면 이 레포는
설치 파일 저장소로 굳고, 고도화는 멈춘다.

각 자산의 README에 누적 루프가 정의돼 있다. 프로젝트 종료 시 그 루프를 돌려라.
