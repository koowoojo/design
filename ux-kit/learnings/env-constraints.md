# env-constraints — 환경별 제약

한 번 확인한 환경 제약은 여기 쌓아두고, `context/*.md` 의 §1로 복사해 쓴다.
**이 파일은 승격 대상이 아니다.** 규칙 본문이 아니라 조직 컨텍스트로 흘러간다.

## 템플릿

```
## [환경명]
- 실행 주체:
- 확인 일자:
- 확인 방법:   ← 문서를 봤는지, 실제로 테스트했는지. 추측이면 추측이라고 써라
- 제약:
- 금지 문법·기능:
```

---

## (예시 — 실제 확인 후 대체할 것)

## 소비자 모바일 앱 (RN/Flutter, iPhone 13 Pro 기준)
- 실행 주체: 사진을 많이 찍는 일반인, 야간 한 손 (원문 PRD는 영유아 부모. 2026-09-04 범위 확대)
- 확인 일자: 2026-09-04
- 확인 방법: **추정** — 요구사항 문서 추출. 실기기 미측정. HTML 시안(390×844)만 브라우저에서 클릭 검증
- 제약: 세로 고정, 호버 없음, 탭 ≥48pt, A15 10초, 갤러리 쓰기, Apple Intelligence 금지
- 금지 문법·기능: 웹/PWA를 최종 실행으로 가정, 호버 의존 인터랙션

## webOS TV 브라우저
- 실행 주체: 매장 전시 TV
- 확인 일자: 미확인
- 확인 방법: **미확인 — 아래는 일반적 추정이며 실제 테스트로 대체할 것**
- 제약: 호버 상태 없음(리모컨 포커스), 시청 거리 2~3m로 폰트 상향 필요
- 금지 문법·기능: 최신 CSS 선택자 계열 — 실제 지원 범위는 기기별로 확인 필요
