## 2. 스펙 이탈 분석

세션 리포트의 이탈 목록을 옮기고, 각각에 대해 판정한다.

| # | 확정 → 실제 | 사전 고지했나 | 왜 이탈했나 | 규칙의 어느 장치가 막았어야 했나 |
|---|---|---|---|---|
| 1 | | | | |

**이탈이 0이 아니라면**: 구조 잠금(§7-3)의 어느 부분이 샜는지 한 문단으로 정리하라.
"에이전트가 규칙을 안 지켰다"는 분석이 아니다. **규칙이 지키기 어렵게 쓰여 있었는지**를 봐라.
