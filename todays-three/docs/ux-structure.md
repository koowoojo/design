| # | 사례 (유형) | 왜 가져왔는지 |
|---|---|---|
| 1 | 하루 1장 일기형 앱의 Today 홈 | 홈이 "오늘을 했는가 / 안 했는가" 이분법. 핵심 순간이 한 번의 마감이다 |

## 2. UX 설계 — 2안

출력 순서: 여정 → 화면 목록+목적 → 핵심 순간 → 정보 위계는 후보만.

### A안 (추천) — 코스 수락형

PRD가 이미 잠근 심장: 열면 3장과 확정. 묶음은 접혀 통제감만 담당.

**여정**

```
[최초] 짧은 고지(무엇/사진취급/권한)
    → [매번] 처리(≤10초, 점수 없음)
    → 오늘의 3장 (미확정)
         ├─ 그대로 확정 ─────────→ 봉인 → 오늘이 닫힘
         │                              └─ (선택) 공유. 커머스 없음
         └─ 묶음 펼침 → 자리 교체 1회 이상 → 확정 → 동일
    → 같은 날 재방문: 처리 없이 봉인된 오늘 카드
    → 앨범 탭: 쌓인 카드. 여기서만 포토북
```

로그인·설정 허브·삭제·점수 화면은 여정에서 나오지 않아 목록에 넣지 않는다.

**화면 목록과 목적**

| 화면 | 목적 |
|---|---|
| 고지 1 — 무엇 | 이 앱이 정리 도구가 아니라 하루를 닫는 도구임을 한 번에 |
| 고지 2 — 사진 | 원본 미전송 / 512px 후보만 / 서버 미저장을 고지하고 진행 |
| 고지 3 — 동의·권한 | 사진 접근. 다른 사람 사진은 골라도 되는지 확인. 국외 이전은 폴백 시에만 |
| 처리 중 | 기다림을 "평가"가 아니라 "오늘을 고르는 중"으로 |
| **오늘 · 미확정** | 결정을 끝낸다 |
| 묶음 펼침·교체 | 못 믿을 때만 자리를 바꾼다 |
| 봉인 | 닫혔다는 감각. 다음 할 일 없음 |
| 오늘 · 봉인 | 같은 날 재방문. 일 1회 제한이 제한처럼 안 보이게 |
| 공유 시트 | 3장을 내보낸다. 마감을 막지 않음 |
| 월별 앨범 | 쌓인 카드를 본다 |
| 포토북 시트 | 앨범에서만. 하루 마감을 침범하지 않음 |
| 빈 상태 | 오늘 사진 없음 |
| 권한 거부 | 갤러리를 읽을 수 없을 때 다음 행동 하나 |

**핵심 순간 (1개)**  
앱을 열었을 때 3장이 이미 있고, 엄지가 `이걸로 결정`에 닿아 있다.

**정보 위계 후보**  
3장 세트 > 닫기 버튼 > 접힌 장면 목록. 점수·AI 문구·커머스는 이 화면에 후보조차 아님.

### B안 — 후보 개방형

**여정**  
처리 후 3장이 상단에 고정되고, 그 아래 후보 10~15장이 항상 보인다. 확정은 같다.

**화면 목록**  
A안보다 묶음 화면이 독립되지 않고 오늘 화면에 흡수. 앨범·공유·고지는 동일.

**핵심 순간**  
약해진다. 열자마자 고를 거리가 다시 생긴다.

**정보 위계 후보**  
3장 ≈ 후보 그리드 > 닫기. PRD의 "결정은 1번, 통제감은 묶음"과 충돌.

### 추천과 근거

**A안.** PRD §3이 첫 화면과 성공 정의를 이미 잠갔다. B안은 갤러리 스와이프의 결정 피로를 화면 안으로 다시 넣는다. A안의 묶음은 불신 시에만 열린다.

## 3. 텍스트 시안 — 3안 (핵심 순간 = 오늘 · 미확정)

축: 정보 위계 > 상호작용 > 안전–도전. 톤은 이 단계에서 다루지 않는다.

### 1안 안전형 (추천 · 렌더링)

- **목적**: 세트를 한눈에 보고, 생각 없이 닫는다
- **정보 위계**: 동등한 3장(순위 없음) > 닫기 > 접힌 장면
- **영역 분할**: 날짜/제목 → 3분할 트립틱 → 닫기(항상 보임) → 장면 목록 → 오늘/앨범 탭
- **주요 컴포넌트**: 트립틱 카드, 단일 Primary 버튼, 아코디언 행(행 전체 탭, ≥48pt), 하단 2탭
- **주요 상호작용**: 닫기 1탭. 장면 행 탭 → 후보 2장. 후보 탭 → 트립틱 자리 점멸 → 자리 탭 → 교체. 중첩 아코디언 없음
- **상태**: 처리 중(짧은 문구 3단계, 점수 없음) / 빈(오늘 사진 없음) / 에러(권한·네트워크는 "다시 시도" 하나)
- **요구 기술**: 갤러리 읽기·즐겨찾기·앨범 쓰기(시안 밖). 시안은 상태만 재현

닫기 버튼이 3장을 스크롤해야 나타나면 핵심 순간이 죽는다. 트립틱으로 3장을 접어 넣고 닫기를 같은 화면에 둔다. 세로 스택은 동등함은 좋지만 접힘면(fold)을 깬다.

### 2안 절충형

- **목적**: "오늘 카드"가 이미 인쇄물처럼 보이게 해서 확정이 박제로 이어짐을 미리 보여 줌
- **정보 위계**: 2+1 콜라주 카드 > 닫기 > 장면
- **영역 분할**: 큰 1장 + 작은 2장 = 하나의 카드 모듈. 닫기는 카드 하단
- **상호작용**: 1안과 같음. 자리 교체 시 큰 칸/작은 칸이 위계처럼 읽힘
- **상태**: 1안과 동일
- **리스크**: 크기 차이가 점수·순위처럼 보여 §3·§9(사람 외모·점수 평가)와 마찰

### 3안 도전형 (코스 요리 투입)

- **목적**: 평가 UI를 제거하고 코스를 받듯 수락만 남긴다
- **정보 위계**: 한 장의 코스 카드(3장이 겹친 접시) > "이대로 오늘을 닫기" > 장면은 하단 시트 핸들
- **영역 분할**: 화면 거의 전부 = 세트. 장면은  multimodal 시트가 아니라 손잡이만
- **상호작용**: 기본 경로는 버튼 하나. 교체는 시트를 올려야 함. 자리 대응이 겹침 때문에 흐림
- **상태**: 처리 중을 "주방에서 오늘 코스를 내는 중" 은유로 — 카피가 제품을 설명하기보다 연출함
- **리스크**: 야간 한 손에서 겹친 사진의 교체 자리가 안 보임. 60초·무교체 목표와는 맞지만 **통제감(묶음)** 이 사라져 킬러 가정 실패 시 탈출구가 없음. PRD가 묶음을 접힌 채로 화면에 두라고 했으므로 구조 이탈

### 시안 체크리스트

| 항목 | 1안 | 2안 | 3안 |
|---|---|---|---|
| 목적 | 세트 수락 | 카드 예고 | 코스 수락 |
| 정보 위계 | 동등 3장 > 닫기 > 장면 | 콜라주 > 닫기 > 장면 | 겹친 세트 > 닫기 > 시트 |
| 영역 분할 | 트립틱 + 고정 닫기 + 목록 | 2+1 카드 | 풀블리드 + 핸들 |
| 주요 컴포넌트 | 트립틱, Primary, 아코디언, 2탭 | 카드 모듈 | 스택 폴라로이드, 시트 |
| 주요 상호작용 | 닫기 / 행→후보→자리 | 동일 + 칸 크기 위계 | 닫기 / 시트 교체 |
| 상태 (로딩·빈·에러) | 있음 | 있음 | 있음 |
| 요구 기술 조건 | 네이티브 이식 가능 | 동일 | 시트 제스처가 웹 시안에서 과장되기 쉬움 |

**렌더링 제안: 1안.**  
동등한 3장은 점수 부재와 맞고, 닫기가 접힘면에 있으며, 접힌 장면이 PRD의 통제감을 지킨다. 2안의 크기 위계와 3안의 묶음 은닉은 잠글 구조가 아니다.

## 4. 구조 잠금 — **확정** (사용자 `4`, 2026-09-04)

사용자가 시안 게이트에서 `4`를 보내 여정 A · 시안 1안 · 일반 사용자 청중을 **잠갔다.**
이 절을 바꾸려면 구조 변경 승인(`1` 변경 / `2` 유지 / `3` 논의)이 필요하다. 승인 없이 시안·스펙을 바꾸지 않는다.

잠기는 것:

- 여정 A안
- 화면 목록 (고지 3 · 처리 · 오늘 미확정/확정 · 교체 · 공유 · 앨범 · 포토북 · 빈 · 권한거부 · 앨범 `···` 개인정보)
- 핵심 순간: 동등한 3장 + `이걸로 결정`
- 정보 위계: 동등 3장 > 확정 CTA > 접힌 장면
- 영역 분할: 트립틱 / Primary CTA / 아코디언 / 2탭(오늘·앨범)
- 청중: 사진을 많이 찍는 일반인 (여행·일상 포함. 부모 전용 아님)
- 용어(시안 `COPY`와 동일): `오늘의 3장`, `이걸로 결정`, `다른 사진`, `오늘 사진이 정해졌어요`, `바꿀 사진을 눌러 주세요`. `AI 추천`, `점수`, `삭제`, 부모·아이·법정대리인 기본 경로 금지
- 공통 규칙: 확정 직후 커머스 없음. 확정 후 교체 없음. 일 1회. 나머지 장 미노출

잠기지 않는 것: 색·폰트·간격·아이콘·더미 장면명(현재 더미: 카페·점심·거리·노을·저녁·밤)
