# 오늘의 3장 — 요구사항 원문

입력은 2026-09-04 세션의 사용자 메시지 본문이다. 인터뷰 39턴(2026-08-26) 확정본.

구현·시안은 이 문서의 잠긴 결정을 뒤집지 않는다. 아래는 화면 설계에 직접 쓰인 발췌다. 전문은 대화 원문을 따른다.

---

## 한 줄

아이 사진을 매일 찍는 부모가, 그날 밤 30~50장 중에서 고민 없이 오늘의 3장을 확정하고 하루를 닫게 해주는 모바일 앱.

## JTBD

아이 사진 30~50장을 찍은 날 밤에, 나는 고민 없이 오늘의 1~3장을 확정하고 싶다. 왜냐하면 정리를 끝냈다는 느낌으로 하루를 닫고 싶으니까.

## 핵심 화면

앱을 열면 AI가 뽑은 오늘의 3장과 확정 버튼이 보인다. 그 아래 묶음 5~7개는 접혀 있다. 결정은 1번, 통제감은 묶음이 담당한다.

성공: 열자마자 3장이 떠 있고, 부모가 아무것도 바꾸지 않고 확정 버튼을 누른다.

## v1 포함

1. 오늘 사진 불러오기 → 3단계 처리
2. 오늘의 3장 + 확정 버튼 (첫 화면)
3. 접힌 묶음 펼치기 → 자리 교체
4. 확정 시 오늘 카드 + 갤러리 즐겨찾기·앨범
5. 월별 앨범 뷰
6. 3장 공유

## v1 제외

로그인, 상세 점수·레이더, AI 캡션, 대용량 여행 처리, 클라우드 동기화, 사진 삭제, 확정 직후 구매 제안.

## 환경

React Native 또는 Flutter. A15 / 6GB에서 10초. Apple Intelligence 금지. 원본 사진 미전송. 후보 512px만 중계.

## 킬러 가정

부모가 AI의 1~3장을 내 선택으로 받아들인다 — **미검증**. 실패하면 이 설계의 대부분 화면이 무효다.
