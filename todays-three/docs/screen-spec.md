## 3. 화면별 상세

### 3.1 고지 1 — 무엇

- 한 줄: 오늘 사진, 3장만 고르면 끝
- Primary: `시작하기`
- 로그인 없음. 부모 전제 없음

### 3.2 고지 2 — 사진

- 원본은 이 폰에만 있음
- 고를 때 쓰는 작은 미리보기만 잠시 전송
- 서버에 저장하지 않음. 나머지는 지우지 않음
- Primary: `다음`

### 3.3 고지 3 — 동의·권한

- 사진첩을 읽어 3장을 고른다고 알림
- 다른 사람 사진은 골라도 되는지 확인하라는 보편 문구
- 체크 `이 사진으로 3장을 골라도 괜찮아요` 가 켜져야 진행
- Primary: `사진첩 허용` → 권한 후 처리 중
- 국외 이전 문구는 폴백 시에만 (기본 숨김)
- 법정대리인·아이 문구를 기본 경로에 두지 않음

### 3.4 처리 중

- 문구만 3단계: 비슷한 사진끼리 나누는 중 → 흐릿한 사진을 걸러내는 중 → 오늘 남길 3장을 고르는 중
- 진행 바. 장당 점수·미리보기 그리드 없음
- 중단 버튼 없음 (10초. 있으면 결정을 되살림)

### 3.5 오늘 · 미확정 (핵심)

- 날짜 (더미)
- 제목 `오늘의 3장`
- 보조 한 줄: `이 3장이면 오늘 정리는 끝이에요.`
- 트립틱 3칸, 크기 동일. 칸 번호나 점수 없음
- Primary `이걸로 결정` — 트립틱과 같은 화면, 스크롤 없이 도달
- 접힌 `다른 사진` 5~7행. 시간 + 이름 + 사진 수. 행 전체 탭
- 하단 탭: `오늘` / `앨범`
- AI·모델명 비노출

### 3.6 묶음 펼침·교체

- 한 번에 한 줄만 펼침
- 펼치면 사진 2장
- 사진 탭 → 트립틱에 `바꿀 사진을 눌러 주세요`
- 3장 중 하나 탭 → 교체, 목록 접힘, 짧은 확인
- `이걸로 결정`은 그대로 보임

### 3.7 확정 / 오늘 · 확정

- 트립틱에 `확정` 표시. 교체 불가
- 제목 `오늘 사진이 정해졌어요`
- Secondary `공유하기`
- 같은 날 재방문 시 처리 생략
- 포토북 제안 없음

### 3.8 공유 시트

- 카카오톡 / 인스타 / 더보기
- 시트 닫아도 봉인 상태 유지

### 3.9 월별 앨범

- 월 제목 + 닫힌 날 수 (더미)
- 날짜별 3장 미니 트립틱 그리드
- 하단에서만 `이번 달 N장으로 포토북 만들기`
- 우상단 `···` → 개인정보처리방침 시트 (v1 설정 허브 없음). 시안 더미 고지.

### 3.10 포토북 시트

- 앨범에서만 진입
- 제휴 가격 미결. 단가·수수료 숫자 없음
- `나중에` / `자세히 알아보기` (더미)

### 3.11 빈 상태

- `오늘 찍은 사진이 없어요`
- 앨범 탭은 살아 있음

### 3.12 권한 거부

- 한 줄 이유 + `설정에서 허용` (시안은 고지 3으로 되돌림)

## 4. 공통 규칙 · 용어

| 쓴다 | 쓰지 않는다 |
|---|---|
| 오늘의 3장 | AI 추천, 베스트, 점수 |
| 이걸로 결정 | 오늘을 닫기, 봉인, 저장하기 |
| 오늘 사진이 정해졌어요 | 오늘이 닫혔어요, 선정되었습니다 |
| 다른 사진 | 장면, 클러스터, 묶음 |
| 바꿀 사진을 눌러 주세요 | 자리, 슬롯 |

청중: 사진을 많이 찍는 일반인. 부모·아이·법정대리인을 기본 전제로 쓰지 않음.

버튼: Primary 1개. 파괴적 동작 없음.
탭: 오늘, 앨범. 그 외 탭 없음.
