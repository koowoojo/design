## 3. 화면별 상세

### 3.1 고지 1 — 무엇

- 한 줄: 오늘 찍은 사진에서 3장을 고르고 하루를 닫는다
- Primary: `계속`
- 로그인 없음

### 3.2 고지 2 — 사진

- 원본은 기기에 남음
- 후보 10~15장의 512px만 잠깐 전송
- 서버에 저장하지 않음
- Primary: `알겠어요`

### 3.3 고지 3 — 동의·권한

- 만 14세 미만 아동 사진 처리 고지
- `나는 이 아이의 법정대리인입니다` 체크가 켜져야 진행
- Primary: `사진 접근 허용` → 권한 후 처리 중
- 국외 이전 문구는 폴백 시에만 (기본 숨김)

### 3.4 처리 중

- 문구만 3단계: 묶는 중 → 장면을 고르는 중 → 오늘의 3장
- 진행 바. 장당 점수·미리보기 그리드 없음
- 중단 버튼 없음 (10초. 있으면 결정을 되살림)

### 3.5 오늘 · 미확정 (핵심)

- 날짜 (더미)
- 제목 `오늘의 3장`
- 보조 한 줄: `이 3장이면 오늘을 닫을 수 있어요`
- 트립틱 3칸, 크기 동일. 칸 번호나 점수 없음
- Primary `오늘을 닫기` — 트립틱과 같은 화면, 스크롤 없이 도달
- 접힌 장면 5~7행. 시간 + 장면명 + 후보 수. 행 전체 탭
- 하단 탭: `오늘` / `앨범`
- AI·모델명 비노출

### 3.6 묶음 펼침·교체

- 한 번에 한 장면만 펼침
- 펼치면 후보 2장 (묶음당 상위 2장)
- 후보 탭 → 트립틱에 `어느 자리를 바꿀까요` 힌트
- 자리 탭 → 교체, 장면 접힘, 짧은 확인
- 닫기는 그대로 보임

### 3.7 봉인 / 오늘 · 봉인

- 트립틱에 닫힘 표시 (인장). 교체 불가
- 제목 `오늘이 닫혔어요`
- Secondary `3장 공유`
- 같은 날 재방문 시 처리 생략
- 포토북 제안 없음

### 3.8 공유 시트

- 카카오톡 / 인스타 / 더보기
- 시트 닫아도 봉인 상태 유지

### 3.9 월별 앨범

- 월 제목 + 닫힌 날 수 (더미)
- 날짜별 3장 미니 트립틱 그리드
- 하단에서만 `이번 달 N장으로 포토북 만들기`
- 우상단 `···` → 개인정보처리방침 (v1 설정 허브 없음)

### 3.10 포토북 시트

- 앨범에서만 진입
- 제휴 가격 미결. 단가·수수료 숫자 없음
- `나중에` / `자세히 알아보기` (더미)

### 3.11 빈 상태

- `오늘 찍은 사진이 없어요`
- 앨범 탭은 살아 있음

### 3.12 권한 거부

- 한 줄 이유 + `설정에서 허용` (시안은 고지 3으로 되돌림)

## 4. 공통 규칙 · 용어

| 쓴다 | 쓰지 않는다 |
|---|---|
| 오늘의 3장 | AI 추천, 베스트, 점수 |
| 오늘을 닫기 | 저장, 완료, 확정하기 (버튼 라벨) |
| 오늘이 닫혔어요 | 선정되었습니다 |
| 장면 | 클러스터, 그룹, 묶음(내부 용어) |
| 자리 | 슬롯, 교체 대상 |

버튼: Primary 1개. 파괴적 동작 없음.
탭: 오늘, 앨범. 그 외 탭 없음.
